# Documentación Swagger / OpenAPI 3.0 & Postman

Esta carpeta contiene toda la documentación interactiva y especificaciones de la API:

- **`index.html`**: Interfaz interactiva de **Swagger UI** lista para abrir en el navegador y ejecutar peticiones en vivo (*Try it out*):
  - URL en Devilbox: [http://gevento.loc/swagger/index.html](http://gevento.loc/swagger/index.html) (o [http://gevento.loc/api/documentation](http://gevento.loc/api/documentation))
- **`openapi.json`**: Especificación completa OpenAPI 3.0.3 en formato JSON.
- **`openapi.yaml`**: Especificación OpenAPI 3.0.3 en formato YAML.
- **`postman_collection.json`**: Colección lista para importar en Postman o Insomnia con todos los endpoints preconfigurados apuntando a `{{base_url}}` (`http://gevento.loc`).
